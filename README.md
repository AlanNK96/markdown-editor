# Markdown 编辑器

一个基于 Web 的标准版 Markdown 编辑器，提供文本编辑、实时预览、工具栏辅助和文件操作功能。

## ✨ 功能特性

### 核心功能
- ✅ **实时预览**：编辑内容实时渲染为 HTML，支持标准 Markdown 语法
- ✅ **工具栏辅助**：提供常用 Markdown 语法的快捷插入按钮
- ✅ **文件操作**：支持新建、打开、保存本地文件
- ✅ **自动保存草稿**：防止意外关闭导致内容丢失
- ✅ **快捷键支持**：常用操作支持键盘快捷键
- ✅ **视图模式切换**：支持分屏、仅编辑、仅预览三种模式

### Markdown 语法支持
- 标题（H1-H6）
- 粗体、斜体、删除线
- 有序列表、无序列表
- 链接、图片
- 行内代码、代码块（支持语法高亮）
- 引用块
- 水平分割线
- 表格

### 安全特性
- XSS 防护（使用 DOMPurify 清理 HTML）
- 危险链接禁用（javascript:、data: 协议）
- 外部链接安全属性（target="_blank" rel="noopener noreferrer"）

## 📖 使用说明

### 文件操作

#### 新建文件
1. 点击工具栏的"新建"按钮
2. 或使用快捷键 `Ctrl/Cmd + N`
3. 如果当前有未保存内容，会提示确认

#### 打开文件
1. 点击工具栏的"打开"按钮
2. 或使用快捷键 `Ctrl/Cmd + O`
3. 选择 `.md` 或 `.txt` 文件
4. 支持的文件大小：最大 10MB

#### 保存文件
1. 点击工具栏的"保存"按钮
2. 或使用快捷键 `Ctrl/Cmd + S`
3. 文件将以 `.md` 格式下载到本地

### 使用工具栏

工具栏提供了常用 Markdown 语法的快捷插入：

- **标题**：在行首插入 `#` 符号
- **粗体**：包裹选中文本为 `**文本**`
- **斜体**：包裹选中文本为 `*文本*`
- **删除线**：包裹选中文本为 `~~文本~~`
- **链接**：插入 `[链接文本](URL)` 格式
- **图片**：插入 `![描述](图片URL)` 格式
- **行内代码**：包裹选中文本为 `` `代码` ``
- **代码块**：插入代码块模板
- **列表**：插入列表项
- **引用**：在行首插入 `>` 符号
- **水平线**：插入 `---`
- **表格**：插入表格模板

### 视图模式

编辑器支持三种视图模式：

1. **分屏模式**（默认）：左侧编辑，右侧预览
2. **仅编辑模式**：只显示编辑区，专注写作
3. **仅预览模式**：只显示预览区，查看渲染效果

点击工具栏右侧的视图按钮切换模式。

### 草稿自动保存

- 编辑内容会自动保存到浏览器本地存储
- 下次打开页面时会提示是否恢复草稿
- 草稿保存时间：7 天
- 可以手动清除草稿

## 🔒 安全性

### XSS 防护
- 使用 DOMPurify 库清理渲染的 HTML
- 禁止执行用户输入的脚本
- 限制允许的 HTML 标签和属性

### 链接安全
- 外部链接自动添加 `target="_blank"` 和 `rel="noopener noreferrer"`
- 禁用危险协议（javascript:、data:）

### 隐私保护
- 所有操作在客户端完成
- 不收集用户数据
- 草稿仅存储在本地浏览器

## 💡 提示

### 最佳实践
1. 定期保存文件（使用 Ctrl+S）
2. 对于重要文档，建议使用版本控制（如 Git）
3. 浏览器缓存清理可能导致草稿丢失，请及时保存

### 性能优化
- 编辑大文件时，预览可能有轻微延迟（防抖机制）
- 建议单个文件不超过 5000 行

### 故障排除

**问题：预览区不更新**
- 检查浏览器控制台是否有错误
- 刷新页面重试

**问题：无法保存文件**
- 检查浏览器是否禁用了下载
- 确认浏览器兼容性

**问题：草稿无法加载**
- 检查浏览器是否禁用了 localStorage
- 清除浏览器缓存后重试
